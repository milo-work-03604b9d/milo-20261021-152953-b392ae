### Retro-Industrial System Diagnostic Dashboard

A standalone SVG dashboard designed for a retro-industrial aesthetic. 

**Features:**
- High-contrast Amber and Green color palette.
- CRT Scanline effect using an embedded SVG `<pattern>`.
- Three telemetry readouts: Oxygen, Heat, and Structural Integrity.
- Scalable vector graphics (SVG) ensures it can be used in game engines or web interfaces without losing quality.

**Usage:**
Open `dashboard.svg` in any modern web browser or import into a graphics engine.

**Target Audience:**
Indie game developers, UI designers, and retro-tech enthusiasts.
